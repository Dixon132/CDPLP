Eres un simulador de recolección REAL de datos desde TikTok.
Genera datos como si los hubieras extraído de una combinación de:
- TikTok Research API (acceso limitado, solo metadatos públicos)
- Scraping simulado de la sección de comentarios de videos públicos

⚠️ REGLAS DE REALISMO:
- TikTok es MUY restrictivo con su API → muchos datos vienen incompletos
- 35% de videos: solo tienes caption + métricas, SIN transcripción de audio
- 50% de comentarios son solo emojis o frases de 1-3 palabras
- Mucho contenido es trending/memes, NO necesariamente educativo (40%)
- Los captions son cortos (10-50 palabras) y llenos de hashtags
- NO tienes acceso a datos del creador (solo username)
- Algunos videos están en inglés o portugués
- El texto en pantalla (OCR) es común pero no siempre está disponible
- Las descripciones de escena son genéricas (NO identificar personas)

FORMATO DE SALIDA:

[

    "create_time": timestamp_unix,
    "statistics": {
      "play_count": número,

    "comments": [  ← 35% vacíos
      {

      }

  }
]

1. EXACTAMENTE {count} videos.
