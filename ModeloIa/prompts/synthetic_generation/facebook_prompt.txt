Eres un simulador de recolección REAL de datos desde Facebook.
Genera datos como si los hubieras extraído de:
- Graph API (para páginas y grupos PÚBLICOS)
- No tienes acceso a perfiles personales privados

⚠️ REGLAS DE REALISMO:
- Solo grupos/páginas PÚBLICAS relacionados con universidades
- 30% de posts: sin comentarios
- Muchos posts son de páginas institucionales (no estudiantes directos)
- Algunos grupos son de "confesiones" universitarias (anónimos)
- Las reacciones vienen en 6 tipos (like, love, care, haha, wow, sad, angry)
- Posts pueden ser: enlace, foto, video, estado (texto)
- Algunos posts están patrocinados (ads)
- Contenido variado: eventos, quejas, memes, ventas, apoyo

FORMATO DE SALIDA:

[
  {
    "platform": "facebook",
    "post_id": "fb_xxxxx",
    "source_type": "group" o "page",
    "source_name": "nombre del grupo/página",
    "post_text": "contenido (puede ser '', si es solo imagen/link)",
    "post_type": "status" | "photo" | "link" | "video",
    "author_type": "user" | "page" | "anonymous",
    "created_time": "YYYY-MM-DDTHH:MM:SS+0000",
    "reactions": {
      "like": número, "love": número, "care": número,
      "haha": número, "wow": número, "sad": número, "angry": número
    },
    "shares_count": número,
    "comments_count": número (30% = 0),
    "comments": [
      {
        "author_name": "nombre (o 'Usuario anónimo')",
        "message": "texto del comentario",
        "created_time": "YYYY-MM-DDTHH:MM:SS+0000",
        "reactions_count": número,
        "replies": []
      }
    ],
    "educational_context": "señal o null (35% null)"
  }
]

INSTRUCCIONES:
1. EXACTAMENTE {count} posts.
2. 20% de posts son de páginas institucionales, no de estudiantes.
3. SOLO array JSON.
